# 微信小程序「信衡」上线清单

> 目标：把 `miniprogram/` 从开发状态推进到**正式版发布**。
> 代码侧已全部就绪（生产地址、隐私 API、审核账号脚本、构建配置），剩下的都是微信公众平台的后台配置与提审操作，按本文顺序逐项打勾即可。

## 1. 注册小程序 & 获取 AppID

1. 到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册一个小程序账号（企业主体可直接选教育相关类目；个人主体类目受限，见第 4 步）
2. 「开发管理 → 开发设置」复制 **AppID**（`wx` 开头 18 位）
3. 本地注入：

   ```bash
   cd miniprogram
   npm run set-appid -- wx你的真实appid
   ```

   脚本会同时更新 `src/manifest.json`（源头）与已构建产物里的 `project.config.json`，之后每次构建自动带上。

## 2. 服务器域名配置（mp 后台）

「开发管理 → 开发设置 → 服务器域名」，**三组都加同一条**：

| 域名类型 | 域名 |
|---|---|
| request 合法域名 | `https://mengxiangt.top` |
| uploadFile 合法域名 | `https://mengxiangt.top` |
| downloadFile 合法域名 | `https://mengxiangt.top` |

> 不需要配置 COS 桶域名：文件预览/下载经后端代理，小程序只访问 API 域名。
> 域名必须 HTTPS + 已 ICP 备案（mengxiangt.top 已备案）。

## 3. 用户隐私保护指引（不配置则选文件/拍照会被微信拦截）

「设置 → 服务内容声明 → 用户隐私保护指引」，声明收集以下信息（对应小程序实际用到的 API）：

| 收集的信息 | 对应功能 / API |
|---|---|
| 选中的文件 | 提交作业、上传样例（`chooseMessageFile`） |
| 相册（仅写入）| 拍照/选图上传（`chooseMedia`） |
| 摄像头 | 拍照上传（`chooseMedia` sourceType camera） |
| 学号、姓名 | 账号登录与展示（用户注册自行填写） |

> 未声明时，正式版调用上述 API 会被微信直接拦截（提示"该小程序未申请隐私协议"）。

## 4. 服务类目

- **企业主体**：建议「教育服务 → 教学管理」或按后台提示补资质；若资质不全，退而选「工具 → 效率」
- **个人主体**：只能选非限制类目，建议「工具 → 效率」
- 类目决定了审核口径，若首次提审因"类目不符"被驳回，按驳回说明换类目重提即可（不影响代码）

## 5. 审核体验账号（提审必填，否则无法体验登录后功能）

微信审核员需要能登录体验。在生产服务器上执行一次：

```bash
# 服务器上（docker 部署）
docker exec hw_backend node src/seeders/seedReview.js

# 或本地直连数据库：cd server && npm run seed:review
# 自定义密码：REVIEW_PASSWORD=xxx npm run seed:review
```

脚本幂等，创建隔离的演示数据（不碰真实班级）：

| 项 | 值 |
|---|---|
| 学校（登录页下拉选择） | 信衡演示学校 |
| 教师账号 | `review_teacher` / `Xinheng@2026` |
| 学生账号 | `review_student` / `Xinheng@2026` |
| 演示内容 | 演示1班 · 演示课程 · 一个进行中作业 + 一个已截止作业 |

审核通过后如需收回：网页端管理员把两个演示账号**禁用**即可。

## 6. 构建与上传

```bash
cd miniprogram
npm install        # 首次
npm run set-appid -- wx你的真实appid
npm run build:mp-weixin
```

1. 微信开发者工具 → 导入项目 → 目录选 **`miniprogram/dist/build/mp-weixin`**，AppID 自动识别
2. 「详情 → 本地设置」确认没有勾选"不校验合法域名"（用真实域名校验一次，提前暴露配置问题）
3. 真机预览点一遍核心链路：登录 → 作业列表 → 详情 → 选文件提交 → 教师端批改
4. 工具栏「上传」→ 填版本号（如 `1.0.0`）与备注（如"首次发布"）

## 7. 体验版自测（强烈建议，走的是生产 API）

mp 后台「管理 → 版本管理」→ 开发版本 → 选为**体验版**，扫码安装到手机：

- 体验版环境（trial）自动请求 `https://mengxiangt.top`，等于上线前全真演练
- 重点回归：登录/注册、作业提交（含拍照）、文件预览、消息角标、401 过期重登

## 8. 提交审核

mp 后台「版本管理 → 开发版本 → 提交审核」：

1. **体验账号**：填第 5 步的账号密码（学生账号即可），并在备注写明"登录需先在首页选择『信衡演示学校』"
2. **功能页面**：配置审核截图与说明（登录页、作业列表、提交页各一张）
3. **隐私承诺**：如被要求确认用户隐私保护指引，按第 3 步声明内容确认
4. 提审后一般 1~7 天出结果，驳回会附具体原因，改完可立即重提

## 9. 审核通过 → 发布

「版本管理 → 审核版本 → 发布」：

- 首次建议**全量发布**
- 发布后立刻线上验证：搜索小程序 → 登录演示账号 → 走一遍提交作业
- 出问题可「版本管理 → 回退」到上一版本

## 10. 版本迭代约定

- 发版前改 `src/manifest.json` 的 `versionName`（如 `1.1.0`）与 `versionCode`（递增，如 `110`）
- 生产地址变更只需改 `src/utils/config.js` 的 `PROD_BASE_URL`，并在 mp 后台同步改三组合法域名
- 上线后新增隐私类 API（如定位、通讯录）必须先补隐私指引声明再发版

## 常见驳回原因速查

| 现象 | 对策 |
|---|---|
| 「小程序功能与类目不符」 | 换类目（第 4 步）或补资质 |
| 「无法体验完整功能」 | 确认体验账号可登录、演示学校里有进行中作业（重跑 seedReview） |
| 「存在隐私合规问题」 | 核对第 3 步声明的条目与实际用到的 API 一致 |
| 「域名不合法/未备案」 | 域名必须 HTTPS 且备案，三组域名都要配 |
