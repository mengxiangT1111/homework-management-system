## 1. 系统硬约定（必须严格遵守）

1. **API 前缀 `/api`**，响应统一为 `{ code, success, message, data }`。`success === false` 时把 `message` 原样提示给用户。
2. **鉴权**：`Authorization: Bearer <token>`；收到 401 一律清除本地登录态并跳转登录页。
3. **分页**：请求参数 `?page=1&pageSize=10`，返回 `data: { list, total, page, pageSize, totalPages }`。
4. **登录**：`POST /api/auth/login`，body `{ username, password, school_id }`。师生必须选学校（管理员不在小程序范围内）；学校下拉用 `GET /api/schools/all`（免登录）。登录返回 `{ token, user }`，`user.role` ∈ student/teacher/admin，admin 登录后提示"请使用网页端"并拒绝进入。
5. **文件存储**：数据库存 `file_path`，两种格式：`uploads/202607/xxx.pdf`（本地）或 `cos://homeworks/202607/xxx.pdf`（COS）。预览 URL 统一通过 `POST /api/files/urls`（Header 鉴权，body 传路径数组）解析，或直接用 `GET /api/files/download?path=<file_path>&token=<jwt>`。
6. **提交契约**：`POST /api/submissions/assignment/:id`，body `{ files: [{ original_name, file_path, file_size, mime_type, file_hash }], remark }`。逾期/已关闭/超数量/格式不符等校验后端已有，前端只做友好预检与错误透出。
7. **时间**：后端返回 ISO 字符串。小程序里解析时间必须用统一工具函数（把 `-` 替换为 `/` 再 `new Date`，规避 iOS 解析失败）；截止倒计时、逾期红字只做展示，最终判定以后端为准。

## 2. 技术选型（已定，不要更改，不要征询意见）

  `npx degit dcloudio/uni-preset-vue#vite miniprogram`

## 3. 后端唯一新增接口：`POST /api/upload/single`

在 `server/src/controllers/uploadController.js` 与 `server/src/routes/upload.js` 中新增（风格与现有一致，`router.use(auth)` 已覆盖）：

- multer 单文件上传，字段名 `file`，上限 **100MB**，扩展名黑名单与现有一致（`.html/.htm/.svg/.js/.exe/...`）
- `original_name` 优先取 `req.body.filename`（小程序会通过 formData 传入真实文件名），否则用 `file.originalname`；**必须复用 `fixMojibakeName` 处理中文乱码**，并做 basename 清洗
- 落盘规则与 `mergeChunks` 完全一致：年月子目录 + 随机文件名；配置了 COS 时 `uploadToCOS` 并写 `cos://` 前缀路径；未配置 COS 时存本地 `uploads/年月/xxx`
- `file_hash` 置 `null`（小程序端不做全量 MD5）
- 返回 `data` 与 merge 接口完全一致：`{ original_name, file_path, file_size, mime_type, file_hash, ext }`
- 不改动现有 check/chunk/merge/simple 四个接口的任何行为

## 5. 页面规格（P0 共 12 页，全部放主包）

`pages.json` 配 4 个原生 tabBar：**首页 / 作业 / 消息 / 我的**（tabBar 允许省略 iconPath，用纯文字即可，不要为图标引入额外依赖）。

**1. `pages/login/login`**（pages.json 首页设为登录页）
学校 picker（schools/all，默认记住上次选择）→ 学号 → 密码 → 登录。防重复提交；成功后按 `user.role` 处理：student/teacher 进首页（`uni.reLaunch`），admin 提示请用网页端。启动时 `App.onLaunch` 用 `GET /api/auth/profile` 校验已有 token，失败清态留在登录页。

**2. `pages/index/index`**（tab 首页，按 role 分支）
- 学生：顶部问候 + `stats/student` 概览卡；"待交作业"列表（`GET /api/assignments?status=active` 取前 5 条，显示课程/标题/截止倒计时，逾期红字）；快捷入口（提交记录、消息、我的班级）
- 教师：`stats/teacher` 统计卡（读 statsController 后展示有意义字段）；近期截止作业列表；快捷入口（创建作业、AI 批改复核队列）

**3. `pages/assignments/list`**（tab 作业，按 role 分支）
- 学生：全部作业列表，下拉刷新 + 触底加载分页；每项显示课程名/标题/截止时间/状态标签
- 教师：顶部课程 picker（courses/my/teaching，"全部课程"选项）筛选；右上角"创建作业"按钮；status 筛选（进行中/已关闭）

**4. `pages/assignments/detail?id=`**
- 学生：作业要求卡（说明/格式 chips/最多份数/单文件上限/截止时间/样例文件可下载）→ 我的提交卡（状态/分数/评语/文件列表，`GET /api/submissions/my/assignment/:id`）→ 提交按钮（`status=closed` 或已逾期则隐藏并显示原因条）
- 教师：提交进度概览（已交/未交数）→ 已交列表（学生名/时间/分数/状态，点进批改页）→ 未交名单（可折叠）→ "催交"按钮（confirm 后调 remind）→ AI 批改入口（任务进度轮询条：发起 batch / 展示 progress / 取消）

**5. `pages/assignments/submit?id=`**（学生提交页）
- 文件选择：`uni.chooseMessageFile`（type=file，可传 extension 过滤）与 `uni.chooseMedia`（拍照/相册）两个入口；数量、单文件大小（max_size_mb）、扩展名（allowed_formats）前端预检
- 逐个**串行** `uni.uploadFile` 到 `BASE_URL + /api/upload/single`（name='file'，formData 传 `filename`，Header 带 token），显示总进度与单文件状态；失败可单文件重试
- `uni.uploadFile` 的 `res.data` 是字符串，需 `JSON.parse`
- 备注 textarea（可选）→ 全部文件上传完成后 `POST /api/submissions/assignment/:id` 提交 descriptor 数组；成功后返回详情页并刷新
- 超过 100MB 的文件直接拦截并提示"请到网页端提交"

**6. `pages/submissions/my`**（学生提交记录）
`GET /api/submissions/my/list` 分页列表：课程/作业标题/提交时间/状态标签/分数；点击跳对应作业详情。

**7. `pages/teacher/create-assignment`**（教师创建作业）
表单：标题（必填）、说明（textarea）、课程 picker（必填）、截止时间（picker mode=date + time，必填）、allowed_formats 多选 chips（默认 pdf/doc/docx/jpg/png/zip）、max_files 数字、max_size_mb 数字、need_grading switch。提交 `POST /api/assignments`，成功返回列表刷新。

**8. `pages/teacher/review?submissionId=`**（教师批改）
- `GET /api/submissions/detail/:id`：学生信息 + 提交时间 + 文件列表
- 每个文件可预览（方案见第 6.3 节）
- 打分 input（数字，按作业是否 need_grading 展示）+ 评语 textarea → `PUT /api/submissions/:id/grade`
- AI 结果只读卡：`GET /api/grading/results/submission/:submissionId`，有则展示得分/理由/置信度，无则显示"未进行 AI 批改"

**9. `pages/notifications/notifications`**（tab 消息）
分页列表（type 标签色：deadline/grade/system/assignment）、点按标记已读并跳转 related 业务页、"全部已读"按钮；进入时清角标。

**10. `pages/mine/mine`**（tab 我的）
头像占位 + 姓名/学号/学校/角色徽章；功能列表：修改密码、（学生）我的班级、（教师）我的课程、退出登录（confirm）。

**11. `pages/mine/password`**
原密码 + 新密码 + 确认新密码 → `PUT /api/auth/password`，成功后 toast 并要求重新登录。

**12. `pages/mine/classes`**（学生）
我的班级卡（`classes/my/list`：班级/学校/身份；有退出按钮）；"浏览可加入班级"（`classes/all/list` 过滤本校）+ 加入按钮（confirm；后端限制一个学生一个班，错误透出）。

## 6. 关键实现方案

### 6.1 请求层 `utils/request.js`
- Promise 化 `uni.request`；自动注入 token；`success === false` → `uni.showToast(message)` 并 reject；HTTP 401 → 清 storage + `uni.reLaunch` 登录页；无网络/超时统一文案
- 导出 `get/post/put/del` 四个方法；上传走独立 `uploadFile` 封装（同样带 token、JSON.parse 响应）

### 6.2 环境配置 `utils/config.js`
- `BASE_URL`：开发环境 `http://<本机局域网IP>:3000`（真机调试需同一局域网），生产 `https://你的域名`，用注释说明切换方式
- `manifest.json` 的 mp-weixin appid 用占位 `touristappid`，并在 README 标注替换位置

### 6.3 文件预览 `utils/preview.js`
- `POST /api/files/urls` 拿 URL（COS 公共读桶直出）→ `uni.downloadFile` → 按扩展名分流：图片 `uni.previewImage`；pdf/doc/docx/xls/ppt `uni.openDocument`；其他格式提示"该格式请在网页端查看"
- 下载失败兜底：改用 `GET /api/files/download?path=xxx&token=xxx` 再试一次
- 注意：COS 域名与 API 域名都必须加入小程序后台 downloadFile 合法域名（写进 README 检查单）

### 6.4 消息角标
- tab 页 `onShow` 调 `GET /api/notifications/unread/count`，>0 时 `uni.setTabBarBadge({ index: 2, text })`，=0 时 `removeTabBarBadge`

### 6.5 通用
- `utils/format.js`：日期时间（iOS 安全解析）、文件大小人性化、剩余时间文案（"剩 3 天 2 小时"/"已逾期"）
- `constants/statusMaps.js`：作业/提交/通知的状态→文案+颜色映射，与 `client/src/utils/statusMaps.js` 保持一致
- `components/empty-state.vue`：统一空态（图标字符 + 文案）
- 分页逻辑封装成可复用的 mixin/composable（下拉刷新 + 触底加载 + 空态）
