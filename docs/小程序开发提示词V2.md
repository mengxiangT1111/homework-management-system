## 1. 系统硬约定（已核实，必须严格遵守）

1. **API 前缀 `/api`**，响应统一 `{ code, success, message, data }`。`success === false` 时把 `message` 原样 toast 给用户。
2. **鉴权**：`Authorization: Bearer <token>`。任何 401 → 清除本地登录态 + `uni.reLaunch` 到登录页；并发请求同时 401 时只处理一次（跳转去重）。
3. **分页**：`?page=1&pageSize=10` → `data: { list, total, page, pageSize, totalPages }`。
4. **登录**：`POST /api/auth/login`，body `{ username, password, school_id }`（师生必选学校；`GET /api/schools/all` 免登录）。返回 `{ token, user }`。登录接口有 IP 限流（15 分钟 10 次），失败提示直接透出服务端 message。`user.role === 'admin'` 时提示"请使用网页端登录"并不进入系统。
5. **文件访问**（最容易做错的点，务必按此实现）：
   - 统一用 `POST /api/files/urls`，Header 带 token，body `{ "paths": ["uploads/202607/xx.pdf", "cos://homeworks/202607/yy.docx"] }`（≤100 项）
   - 返回 `data` 为映射表 `{ "uploads/202607/xx.pdf": "https://...签名URL", "cos://...": null }`（无权访问/不存在时该键为 null）
   - **COS 文件返回签名 URL（1 小时时效）——必须即用即取，禁止缓存或落库**
   - **本地文件返回的是相对路径 `/api/files/download?path=...&token=...`——调用 `uni.downloadFile` 前必须拼上 `BASE_URL`**
6. **提交契约**：`POST /api/submissions/assignment/:id`，body `{ files: [{ original_name, file_path, file_size, mime_type, file_hash }], remark }`。同一作业重复调用=覆盖更新（后端 upsert）。逾期/已关闭/超量/格式错误由后端校验，前端做预检 + 错误透出。
7. **作业列表自带聚合字段**（`GET /api/assignments` 每行）：`is_overdue`；学生视角 `my_submission`（提交对象或 null）；教师视角 `submit_count`；含 `course`（含 `class.name` 班级名）与 `teacher.real_name`。学生"待交作业"直接客户端过滤 `status==='active' && !my_submission`，**不要逐个发请求查询提交状态**。
8. **时间**：解析一律走 `utils/format.js` 的 `parseDate`（把 `-` 替换为 `/` 再 `new Date`，规避 iOS NaN）。倒计时/逾期红字仅做展示，判定以后端为准。
9. **打分**：`PUT /api/submissions/:id/grade`，body `{ score, comment }`；服务端校验 0–100（若该提交已有 AI 结果且模板满分 >100 则上限放宽），前端预检 0–100，越界时透出服务端 message。

## 3. 后端唯一新增接口：`POST /api/upload/single`

在 `server/src/controllers/uploadController.js` + `server/src/routes/upload.js` 新增（`router.use(auth)` 已覆盖，风格与现有一致）：

- multer 单文件，字段名 `file`，上限 **100MB**，扩展名黑名单与现有一致
- `original_name`：优先 `req.body.filename`（小程序通过 formData 传真实文件名），否则 `file.originalname`；**必须复用 `fixMojibakeName` 处理中文乱码**，再做 basename 清洗
- 落盘规则与 `mergeChunks` 完全一致：年月子目录 + 随机文件名；配置了 COS 则 `uploadToCOS` 并写 `cos://` 前缀路径，否则存本地
- `file_hash` 置 `null`（小程序端不做全量 MD5）
- 返回与 merge 完全一致：`data: { original_name, file_path, file_size, mime_type, file_hash, ext }`
- **不改动**现有 check/chunk/merge/simple 四个接口的任何行为

## 5. 页面规格（P0 共 13 页，全部主包）

**1. `pages/login/login`**：学校 picker（记住上次选择）→ 学号 → 密码 → 登录（防重复提交）。成功后 student/teacher `uni.reLaunch('/pages/index/index')`；admin 提示用网页端。`App.onLaunch` 用 profile 接口校验已存 token，失败清态。

**2. `pages/index/index`**（tab，按 role 分支）
- 学生：问候 + `stats/student` 概览卡 + "待交作业"（`assignments?status=active` 前 5 条，客户端过滤 `!my_submission`，显示课程/标题/截止倒计时，逾期红字）+ 快捷入口（提交记录、消息、我的班级）
- 教师：`stats/teacher` 统计卡 + 近期截止作业 + 快捷入口（创建作业、复核队列）

**3. `pages/assignments/list`**（tab，按 role 分支）
- 学生：全部作业（下拉刷新 + 触底分页），卡片显示课程名/标题/截止时间/状态胶囊（进行中/已截止/已逾期），已提交的显示分数或"已提交"
- 教师：课程 picker（courses/my/teaching，含"全部"）+ status 筛选（全部/进行中/已关闭）+ 右上角"创建作业"按钮

**4. `pages/assignments/detail?id=`**
- 学生：作业要求卡（说明/格式 chips/份数/单文件上限/截止/样例文件可预览下载）→ 我的提交卡（`GET /api/submissions/my/assignment/:id`，判 null；已提交显示状态/分数/评语/文件列表）→ 提交按钮：未提交="提交作业"；已提交且未逾期="重新提交（将覆盖）"（二次确认）；已关闭或逾期=隐藏按钮显示原因条

**5. `pages/assignments/submit?id=`**（学生）
- 文件选择：`uni.chooseMessageFile`（type=file，可传 extension 过滤）+ `uni.chooseMedia`（拍照/相册）两个入口；已选文件列表可删除

**6. `pages/submissions/my`**（学生提交记录）：分页列表（课程名/作业标题/提交时间/状态胶囊/分数），点击跳作业详情。

**7. `pages/teacher/edit-assignment?id=`**（教师创建/编辑，一页两用）：按是否有 id 区分模式；表单：标题（必填）/说明/课程 picker（编辑时锁定）/截止 date+time picker（合成 `YYYY-MM-DD HH:mm:ss`，须晚于当前）/allowed_formats 多选 chips（默认 pdf,doc,docx,jpg,png,zip）/max_files/max_size_mb 数字/need_grading switch。创建 `POST /api/assignments`；编辑 `PUT /api/assignments/:id`（先 GET 详情预填）。成功返回列表刷新。

## 6. 关键实现方案

### 6.1 请求层 `utils/request.js`
- Promise 化 `uni.request`；自动注入 token；`success === false` → toast(message) + reject；HTTP 401 → 清 storage + reLaunch 登录页（并发去重）；网络错误/超时统一文案"网络异常，请稍后重试"
- 导出 `get/post/put/del`；`uploadFile(url, filePath, filename)` 独立封装（带 token、timeout 300s、JSON.parse、按 success 判定）

### 6.2 环境配置 `utils/config.js`
- `BASE_URL`：开发 `http://<本机局域网IP>:3000`（真机调试同局域网），生产 `https://你的域名`，注释说明切换
- 禁止把 `/api/files/download` 相对路径直接交给 downloadFile（必须拼 BASE_URL，见硬约定 5）

### 6.3 文件预览 `utils/preview.js`
- 流程：`POST /api/files/urls` 即时取 URL（本地路径结果拼 BASE_URL）→ `uni.downloadFile` → 分流
- `uni.openDocument` **显式传 fileType**：pdf→pdf、doc→doc、docx→docx、xls→xls、xlsx→xlsx、ppt→ppt、pptx→pptx；图片走 `uni.previewImage`；zip/其他 → "该格式请在网页端查看"
- 预览失败自动重取一次 URL 再试；仍失败提示"预览失败，请稍后重试"

### 6.4 消息角标
- tab 页 onShow 调 unreadCount → `uni.setTabBarBadge({index:2, text:String(n)})`；=0 时 `uni.removeTabBarBadge({index:2})`

### 6.5 通用
- `utils/format.js`：`parseDate`（iOS 安全）、日期时间格式化、文件大小人性化、剩余时间文案（"剩 3 天 2 小时"/"已逾期"）
- `constants/statusMaps.js`：作业（active/closed/逾期）、提交（submitted/graded/returned）、通知类型的文案与颜色，与 Web 端 statusMaps 对齐
- `components/empty-state.vue` 统一空态
- 分页 mixin（下拉刷新 + 触底加载 + 空态 + 加载中）

## 7. 陷阱清单（实现时逐条对照，均为高频翻车点）

1. **easycom 未配置 → uni-ui 组件全部静默不渲染**（配置见第 2 节）
2. **本地文件预览用了相对路径 → downloadFile 报 url invalid**（必须拼 BASE_URL）
3. **签名 URL 被缓存复用 → 1 小时后预览全部 403**（即用即取）
4. **uploadFile 不设 timeout → 大文件 60s 必超时**（显式 300s）
5. **`uni.uploadFile` 的 `res.data` 是字符串**（必须 JSON.parse 且判 success）
6. **iOS `new Date('2026-08-30 23:59')` 返回 Invalid Date**（统一 parseDate）
7. **`GET /api/submissions/my/assignment/:id` 未提交时 data 为 null**（判空再渲染）
8. **批量批改漏传 template_id → 422**（必须先拉模板列表让教师选）
9. **任务进度轮询不停止**（终态后 clearInterval；页面 onUnload 也清理）
